# v0.2.0 — 用自然语言控制美居空调

本版提供美居 MCP 与配套 `meiju-control` Skill。完成安装和本机登录后，可以直接对 Agent 说“打开客厅空调”“看看卧室的温度”“把刚才那台关上”。

1. **按名字选设备：**结合家庭、房间和设备名定位，唯一明确匹配就执行，多个候选或相似名称先询问。
2. **完整对话示例：**从首次登录到查询、开关机、组合设置、歧义澄清和失败处理，都有可直接参考的说明。
3. **公开验证边界：**记录一台 `KFR-35G/N8HE1ⅡPro` 的真实登录、读取、单次开机和关机，其他型号与独立温度、模式、风速控制仍待验证。

## 安装与升级

Python 3.11+，仅支持能启动本地 stdio MCP 的客户端；登录页面必须在运行 MCP 的同一台机器打开。设备需先绑定在官方美居 App。

源码 ZIP / sdist 包含完整项目与 Skill；wheel 仅安装 Python 服务；Skill ZIP 可单独安装。安装流程见 [README](../../README.md)，日常用法见 [Skill 对话指南](../../skills/meiju-control/references/conversations.md)。

本版没有改变 7 个工具的参数或控制协议。升级并重启 MCP 后需要重新登录；不要在需要保留旧会话时重启。不同进程之间不共享账号会话。

## 已知限制

- 项目为独立实验性实现，没有美的或美居官方背书。
- 本地离线检查和打包验证不等于所有客户端、型号或操作均通过实测。
- 历史真机证据来自 v0.1.0 代码基线；本版未再次发送真实短信或控制设备。
- 云端接受和回读匹配不证明设备实际执行，写入不会自动重试。
- Skill 和 MCP 分别安装；未提供一键安装插件或远程 MCP 登录。

这是供上传准备使用的发布说明；GitHub Release、托管 CI 和 PyPI 发布均为独立步骤。
