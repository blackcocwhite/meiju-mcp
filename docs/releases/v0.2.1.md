# v0.2.1 — 安装指南与原生对话验收

本版把最新安装文档与 Codex 原生验收记录一起交付，让源码、MCP 安装包和独立 Skill 包使用同一版本。

1. **按下载方式安装：**源码和独立 Skill ZIP 分别提供正确路径，补齐 Windows 命令，明确先安装、配置和验收，再登录美居。
2. **确认原生调用：**记录独立 Codex 聊天如何自动选用 Skill，完成新登录、设备列表、温度和候选能力查询，以及找不到目标时的处理。
3. **文档随包分发：**Skill ZIP 增加 `INSTALLATION.md` 与 `VALIDATION.md`，源码 ZIP 和 sdist 包含完整仓库文档，wheel 提供 Python MCP 服务。

## 下载与升级

- `meiju-mcp-0.2.1-source.zip`：源码、测试、文档、Skill。
- `meiju_mcp-0.2.1.tar.gz`：Python 源码发行包，含文档和 Skill。
- `meiju_mcp-0.2.1-py3-none-any.whl`：Python MCP 服务。
- `meiju-control-0.2.1.zip`：独立 Skill、对话示例、安装指南和脱敏验证记录。
- `SHA256SUMS.txt`、`release-manifest.json`：附件校验和构建/验收信息。

安装见 [README](../../README.md) 和 [Skill 安装指南](../agent-skill.md)。要求 Python 3.11+，客户端支持本地 stdio MCP，浏览器与 MCP 在同一台机器运行。项目仍为实验性预发布，未发布到 PyPI。

## 会话与验证边界

本版没有改变运行逻辑或新增硬件控制能力，不要求现有用户立即重启。会话保存在进程内存中；主动升级并重启 MCP 后需要重新登录，不会自动继承其他进程或旧 App 的会话。

随包记录的原生 Codex 验收来自 v0.2.0：发现 7 个工具，实际调用登录状态、登录入口、设备列表、状态和能力 5 个工具；没有执行原生控制或退出工具。历史物理开关机证据仅覆盖一台 `KFR-35G/N8HE1ⅡPro`，不代表所有型号、其他客户端或所有控制字段都兼容。

完整证据范围见[验证记录](../validation.md)。GitHub 发布与跨平台 CI 状态以仓库对应 tag 和 Actions 为准。
