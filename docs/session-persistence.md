# 本机安全登录态持久化（未发布开发功能）

本页描述未发布的 **Python** 持久化实现。Go 的独立固定助手和 Profile 身份机制分别见[固定助手](fixed-vault-helper.md)与[目录迁移](profile-migration.md)。发布的 v0.2.1 附件不包含这些开发功能。

此功能尚未包含在 v0.2.1 Release 中。源码版本号暂未提升；本文描述当前开发工作区。

## 用户流程

首次登录时，在本机页面自行勾选默认未选中的「记住这台电脑」。只有用户提交登录、云端验证成功且登录链接仍有效后，服务才尝试安全保存。保存失败时页面明确显示「本次已登录，但未能安全保存」，不会退回明文文件。

之后启动使用同一存储目录的 MCP 时，会自动恢复登录态。`meiju_login_status` 的 `authenticated: true` 仅表示进程持有令牌；`validation_status: unvalidated` 表示尚未经本轮云端请求验证。Agent 应重新列举设备，获取本次进程的设备 ID，再匹配家庭、房间与名称。不能复用旧进程的设备 ID，也不能因为恢复成功就宣称令牌仍有效。

目前只持久化 `accessToken` 与客户端设备标识，没有实现 refresh token 协议。服务端明确拒绝令牌时仍需人工登录。网络异常不删除凭据，不自动发送短信，不自动重试设备控制。

## 生命周期与共享范围

- 进程关闭、宿主回收、电脑重启：清理内存和监听器，保留已保存登录。
- 默认目录下，同一系统用户的新版本 MCP 共享一份美居账号。没有多账号选择或跨电脑同步。
- `meiju_logout`：清除当前登录；若使用共享持久化会话，同时删除该目录的保存记录及系统密钥。其他新版本进程在下一次请求前检查变更。已发出的云端请求无法撤回。
- 未勾选保存的登录、`--session-only` 登录相互隔离，退出它们不删除其他进程的保存登录。
- 保存失败后当前进程保持本次内存登录。检查 `persistence_status`；不要把此状态当成已持久化。
- 旧版本进程不支持共享退出检查，不被自动终止。旧 Mac App 的凭据不会读取、迁移或撤销。

## 安全实现

采用 `cryptography` 的 AES-256-GCM，每次保存生成新的 96 位随机 nonce。加密载荷仅包含 token 和客户端设备标识；版本与随机 revision 被绑定进认证数据。不会保存手机号、短信、图形验证码、设备列表或云端完整响应。

256 位随机密钥只存操作系统凭据库；磁盘文件只存密文、格式版本和随机 revision。密钥不写配置、环境变量、命令行或日志。系统访问由专用短命 Python 子进程处理，每次调用最多 12 秒，避免锁定的凭据库无限阻塞 MCP；异常输出固定化。访问密钥可能需要用户响应系统授权提示。

| 平台 | 密钥后端 | 限制 |
| --- | --- | --- |
| macOS | 明确选定 keyring 的 macOS Security/Keychain 后端 | 普通非同步 generic-password 项；不启用 iCloud 同步；系统可能要求授权 |
| Windows | Credential Manager，`CRED_PERSIST_LOCAL_MACHINE` | 仍按当前用户隔离；显式关闭默认企业漫游语义；文件使用当前用户专用 DACL |
| Linux | Secret Service | 需要可用的 D-Bus 用户会话、服务及解锁的凭据库；无桌面环境不保证可用 |

禁止自动选择第三方 keyring 后端、明文后端或文件口令回退。Windows 凭据项只保存短密钥，不受长令牌超过凭据项容量的影响。

每个存储目录独立锁定；保存使用预期 revision 比较、同目录临时文件、fsync 和原子替换。退出写入新的空记录防止旧登录提交复活；令牌失效仅能删除相同 revision，不能误删新登录。不会在进程退出时把旧内存会话重新保存。

目录采用 POSIX 0700 / 文件 0600 或 Windows 用户专用 ACL。拒绝符号链接、重解析点、硬链接及不安全权限。凭据库名称仅包含存储目录的哈希，不包含账号或手机号。损坏的密文拒绝解密；不会尝试猜测或回退。

这些措施保护静态存储，不能抵御同一系统用户的恶意代码、管理员、已被控制的 Python 运行环境或已获设备操作权限的 Agent。普通 Keychain 项不提供“只有此 MCP 能读取”的隔离保证。文件加密也不防御有权限攻击者回滚完整旧备份；云端仍是最终认证与授权方。操作系统或备份软件可能复制密文；应用不提供同步功能。

## 配置、故障和回滚

默认密文目录由 `platformdirs` 决定：

- macOS：`~/Library/Application Support/meiju-mcp/session`
- Windows：当前用户 `%LOCALAPPDATA%\meiju-mcp\session`
- Linux：`$XDG_DATA_HOME/meiju-mcp/session`，未设置时为 `~/.local/share/meiju-mcp/session`

仅本次进程登录（不读、不写、不删除任何保存登录）：

```sh
meiju-mcp --session-only
```

独立验收或隔离账号时给 MCP 配置固定、私有的绝对目录：

```sh
meiju-mcp --session-dir /absolute/private/test-session
```

同一路径恢复同一份登录，不同路径各自独立。不要把此目录放进 Git、共享目录或同步盘；不要使用符号链接路径。

显式忘记指定目录的保存登录并退出：

```sh
meiju-mcp --session-dir /absolute/private/test-session --forget-saved-login
```

省略 `--session-dir` 表示默认目录。这个命令会影响共享该目录的新版本进程，请只在用户明确要求忘记时使用。删除失败返回非零退出码；工具退出失败返回 `logout_incomplete`，不能宣称已彻底清除。进程内存已清除，但仍需处理无法删除的存储。损坏密文可以通过显式忘记恢复，不能自动删除用户文件。

`persistence_status`：`saved` 已保存；`not_saved` 未保存；`disabled` 禁用；`storage_unavailable` 系统服务不可用、锁定、超时或文件操作失败；`storage_key_missing` 找不到密钥；`storage_corrupt` 格式或认证失败；`storage_unsafe` 路径或权限不安全；`session_changed` 共享会话已变化。不要把存储故障解释成云端令牌过期。

启动恢复失败不会覆盖原密文，该进程可以通过人工登录获得本次内存会话；系统问题排除后，在合适时机重新启动该新版本进程以重试恢复。不要循环弹出系统授权提示，不要为了排障结束其他登录进程。

回滚时改用 `--session-only` 或旧版服务。关闭持久化不等于删除已保存数据；需要删除时单独执行上面的忘记操作。旧版会忽略新存储，原登录会话不做自动迁移。

## 验收边界

自动测试使用合成凭据和 MockTransport，不接触真实美居账号。覆盖加密长令牌、原子写失败、篡改拒绝、锁定凭据库、并发保存、共享退出、登录/退出竞争、旧失效结果与新登录竞争、内存模式隔离、过期链接以及 MCP/登录页集成。

macOS 原生凭据库及真人重启恢复结果见 [验证记录](validation.md)。Windows、Linux 原生凭据库尚未在本轮实测；不能将本机 mock 或历史 CI 等同于这两个平台的新功能验收。
