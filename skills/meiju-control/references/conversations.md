# 美居空调：常见对话

以下设备、家庭和回复都是合成示例，用于说明对话方式，不代表已经执行操作。需要已安装本 Skill、连接美居 MCP，并使用自己的账号。温度、模式、风速属于实验性候选控制；示例不构成硬件兼容承诺。

## 第一次使用

**用户：** 帮我打开客厅空调。

**Agent（当前未登录）：** 请打开这次工具返回的本机登录链接，在页面中输入手机号和验证码。登录完成后告诉我，我会继续打开客厅空调。

**用户：** 已登录。

**Agent：** 已找到“示例家庭 / 客厅 / 立式空调”，开机指令已被云端接受，回读显示已开机。

Agent 应先确认登录、读取设备列表和状态，再发送一次开机。手机号和验证码不进入聊天；原请求明确，登录后无需再询问是否开机。当前进程保持登录，后续查询和控制直接复用。

## 列出设备、查询温度

**用户：** 查看我现在的设备列表。

**Agent：** 找到两台空调：客厅“立式空调”和卧室“壁挂式空调”，均在线。

**用户：** 卧室的温度怎样？

**Agent：** 卧室空调上报室温 27°C，设定温度为 26°C，目前关机。这是云端数据，可能存在延迟。

“室温”与“设定温度”分开说明。列表显示在线只代表连接状态，不能当作开机。没有返回室温时，回复“暂时未读到室温”，不拿设定温度代替。

## 开机、关机与连续指代

**用户：** 打开客厅空调。

**Agent：** 客厅“立式空调”的开机指令已被接受，云端回读为开机。

**用户：** 把它关上。

**Agent：** 客厅“立式空调”的关机指令已被接受，云端回读为关机。

Agent 每次刷新设备列表确认目标仍存在；“它”只能指当前会话中已明确选定的一台设备。开关机不附加温度、模式或风速；未获得新的动作请求时不自动恢复之前的设置。

## 调节温度与组合设置

| 用户可以这样说 | 预期操作 |
| --- | --- |
| 卧室空调设为 26°C | 只设置温度，关机状态下不额外开机 |
| 客厅空调切换制冷模式 | 只设置 `mode: cool` |
| 客厅空调风速调到自动 | 只设置 `fan_speed: auto` |
| 卧室空调开机，制冷 26°C，自动风速 | 对同一台设备合并为一次控制调用 |
| 卧室设定温度降低 1°C | 先读取设定温度，再计算并检查范围；读不到时询问绝对值 |

**用户：** 卧室有点热，调舒服一点。

**Agent：** 你希望设为制冷 26°C 并开机吗？

这里需要用户选定具体参数，不能替用户把“舒服”变成一个默认写入。对于“开机，制冷 26°C”等明确请求，不再增加一轮确认。

## 两个家庭里都有客厅

**用户：** 打开客厅空调。

**Agent：** 有两台符合条件：1. 示例家庭甲 / 客厅 / 立式空调；2. 示例家庭乙 / 客厅 / 壁挂式空调。你要打开哪台？

**用户：** 家庭乙那台。

**Agent：** 示例家庭乙客厅“壁挂式空调”的开机指令已被接受，云端回读为开机。

用家庭、房间和设备名定位，不能默认选列表第一台、在线的一台或最近用过的一台。候选编号只在这次选择中有效。

## 相似房间名与明确别名

**用户：** 打开卧室空调。

**Agent：** 没有房间名为“卧室”的精确匹配；列表里有“示例家庭 / 主卧 / 挂机”，你指的是这台吗？

**用户：** 对，我说卧室就是指主卧。

**Agent：** 主卧“挂机”的开机指令已被接受，云端回读为开机。

这条别名只在当前会话中复用，不写成所有用户通用的匹配规则。“客厅空调”如果是设备名，但设备所在房间为卧室，也应先澄清位置冲突。

## 没找到设备或目标离线

**用户：** 打开客厅空调。

**Agent（只有卧室设备）：** 没找到客厅空调，目前列表中只有卧室“壁挂式空调”。

不把唯一设备当成用户指定的另一台。目标明确但离线时，说明离线并停止本次写入，不转移到其他设备，也不自动排队反复尝试。

## 不支持的功能

**用户：** 卧室空调设为 26°C，并打开上下摆风。

**Agent：** 当前工具不能控制摆风。要只设置温度为 26°C 吗？

组合请求有未实现部分时先解释，不悄悄只执行其中一半。定时、睡眠、节能、耗电查询等当前未暴露的功能同样不能通过 raw command 补发。越界温度也不能静默改成边界值。

## 控制结果不确定

**用户：** 打开客厅空调。

**Agent（写入超时）：** 开机请求结果尚未确认。我没有重发；一次只读检查仍显示关机，云端可能有延迟。

应根据实际回执描述；不要承诺“没有执行”，也不要自动重试。需要用户明确要求再次发送，才考虑下一次写入。工具报告 `cloud_match` 也只代表云端目标匹配；用户观察到提示音、导风板或送风，才能补充物理执行证据。

## 退出登录

**用户：** 退出这次美居登录。

**Agent：** 当前 MCP 进程的登录会话已清除。再次使用需要在本机页面登录。

退出登录不等于关机，也不会解绑设备；不要额外发送关机或设备解绑操作。
